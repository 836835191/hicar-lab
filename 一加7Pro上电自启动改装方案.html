一加 7 Pro（骁龙 855 平台）改无电池、上电自启动，本质是两件事：给主板持续供电 + 上电后模拟一次电源键长按。文中所有图纸可直接交给焊接师傅。涉及"测试点"的地方给出了用万用表自行确认的方法——这是最可靠的方式。务必先在台架上用可调电源试通，再装车。

一、方案总览

方案做法评价
A（推荐）拆掉电芯、保留电池排线小板和 NTC → 外部 3.9V 直供 VBAT → MCU 模拟电源键最稳，高通平台认电池，上电必开机
B5V 从 USB-C 进 → MCU 模拟电源键简单，但无电池时部分机型只显示充电图标不开机，且"充电常亮"设置才有效
C淘宝成品"通电自启动模块"免焊，但多数要保留电池，不符合拆电池需求

下文按 方案 A 展开。核心原理：手机开机的条件是 VBAT 有电 + BAT_THERM 检测到 10kΩ（电池常温下） + PWRKEY 被拉低 1~2 秒。我们用外部电源模拟"电池"，用 MCU+光耦模拟"手指按电源键"。

四、手机端拆机与飞线（关键步骤）

4.1 拆机

  1. 关机 → 取卡托 → 热风枪加热后盖四周（约 80~100℃）→ 用吸盘+撬片开后盖。
  2. 第一件事：断开电池排线（防止短路烧主板）。
  3. 拆掉主板盖 14 颗螺丝（有一颗在白色贴纸下），取下盖板。此时电池排线和侧键排线都暴露了。

4.2 电池处理（图2）

不要直接往主板电池座上焊——间距太细，风险大。保留电池自带的排线小 PCB，只把电芯去掉：

   ┌────────────────────────────────────────────┐
   │  电池排线小 PCB（电芯已拆除）                 │
   │                                            │
   │    ┌────┐       ┌────────┐                 │
   │    │ +  ├───────┤ 红线   ├────► 外部 3.9V   │
   │    └────┘       └────────┘                 │
   │    ┌────┐       ┌────────┐                 │
   │    │ −  ├───────┤ 黑线   ├────► GND         │
   │    └────┘       └────────┘                 │
   │                                            │
   │    ┌──────────┐                            │
   │    │ NTC 10kΩ │  保持原样，别动              │
   │    └──────────┘                            │
   │                                            │
   │      ══════════ 排线 ══════════► 插回主板座  │
   └────────────────────────────────────────────┘
  • 用电烙铁/热风枪把电芯镍片从排线 PCB 焊盘上取下，或用斜口钳在远离焊盘处剪断镍片，留下足够焊接的焊盘。
  • 务必保留 NTC。万用表量 NTC 两端，室温应约 10kΩ。若弄坏，在 BAT_THERM 与 GND 之间焊一个 10kΩ 电阻代替。
  • 焊上红/黑硅胶线后，用热缩管绝缘，把排线插回主板。
  • 上电前万用表确认：红线对黑线约 3.9V，NTC 对 GND 约 10kΩ，无短路。

4.3 电源键飞线（图3）

优先方案：焊到侧键排线上的电源按键开关两端。一加 7 Pro 右侧是电源键+音量键软排线，拆下金属盖板即可看到：

   侧键软排线（局部放大示意）

   ┌───────────────────────────────┐
   │  [电源键微动开关]              │
   │     ● A        ● B            │  ← 这两个焊点
   │     └── 按下时 A-B 导通 ──┘    │
   │                               │
   │  [音量+][音量-]  ← 不要焊这里   │
   └───────────────────────────────┘
          │  细线 AWG30 两根
          └──► 引到主板附近，接光耦输出
  • 万用表蜂鸣档确认：未按电源键时 A-B 断开，按住时 A-B 导通。
  • 焊两根极细的线，点少量焊锡，热缩管固定，最好用少量热熔胶做应力释放。

备用方案（找不到开关焊点时）：直接找主板上的 PWRKEY 测试点。方法：万用表黑表笔接主板屏蔽罩（GND），红表笔打蜂鸣/电压档，在主板边缘、电源管理芯片（PMIC）附近的小圆测试点上扫描。找到一个"平时约 1.8V，按住电源键时变成 0V"的点，那就是 PWRKEY。焊一根线到该点，另一根接 GND。

4.4 引出线缆

把电源线（红/黑）和电源键线（A/B）从机身引出。建议从 SIM 卡槽缺口或耳机/USB 口附近的缝隙走线，不要在主板正上方钻孔。用一个 4P 插头汇聚，方便日后维护：

  4P 接口定义：
  1 = VBAT + (红)
  2 = VBAT − (黑/GND)
  3 = PWRKEY A
  4 = PWRKEY B

五、模拟按键电路（图4）

用光耦 PC817，输入侧由 MCU 控制，输出侧直接跨接在电源键开关两端：

   MCU 侧（3.9V 供电，与手机共地）：

        ATtiny85
        PB3(D3) ──┬──[330Ω]──┬──>|──┐
                  │          │ LED │ PC817-1
                  │          └─────┘
                  │                 │
                 GND─────────────────┘

   手机侧（光耦输出，隔离浮地）：

        电源键 A (PWRKEY 信号) ──── C  ┐
                                    ├─ PC817-2
        电源键 B (GND)         ──── E  ┘

工作过程：MCU 的 PB3 输出高电平 → 光耦 LED 亮 → 输出侧 C-E 导通 → 相当于电源键被按下；PB3 变低 → 松开。

若不想用光耦，且 MCU 与手机共地，可直接用 NPN 三极管（S8050）：集电极接 PWRKEY 信号，发射极接 GND，基极经 1kΩ 接 MCU_IO，基极再加 10kΩ 下拉到 GND。效果相同但无隔离。

六、MCU 程序（ATtiny85，Arduino IDE）

先安装 ATTinyCore 板卡包，选择 ATtiny85 @ 8 MHz (internal)，引脚按 ATTiny85 映射（PB3 = D3，PB4 = D4）。

// 一加7Pro 上电自启动 - ATtiny85
// PB3(D3) -> 330Ω -> PC817 LED -> GND   (模拟电源键)
const byte PIN_KEY = 3;

void keyPress(unsigned int ms) {
  digitalWrite(PIN_KEY, HIGH);   // 按下
  delay(ms);
  digitalWrite(PIN_KEY, LOW);    // 松开
}

void setup() {
  pinMode(PIN_KEY, OUTPUT);
  digitalWrite(PIN_KEY, LOW);

  // 等待降压模块和手机 PMIC 稳定
  delay(4000);

  // 模拟长按电源键 1.5 秒
  keyPress(1500);
}

void loop() {
  // 需要"再次补按"的机型可取消下面注释：
  // delay(12000);
  // keyPress(1500);
}

调试方法：若上电后没开机，把 delay(4000) 改成 12000（有些机型要等充电图标出现才认按键），按键时长在 1200~2000ms 之间试。台架上可用 LED 代替光耦先看时序是否正确。

七、台架测试（装车前必做）

  1. 可调电源设 3.9V、限流 3A，接到手机排线红/黑线。万用表量手机端电压应在 3.8~4.0V。
  2. 给 MCU 上电，观察：约 4 秒后光耦动作，再 1~2 秒后手机应震动/亮屏/进开机动画。
  3. 若没反应：查 PWRKEY 飞线是否焊对（按下时是否真的被拉低）；查 NTC 是否 10kΩ；加长上电延时或按键时长。
  4. 能稳定开机后，反复断电/上电 10 次，确认每次都成功。
  5. 断开 3.9V，确认手机正常关机。

八、车载安装（图5）

   汽车保险盒（Acc 供电，例如点烟器/收音机保险）
        │
      [取电器 + 3A 保险丝]
        │
        ├──── 红（+12V）──► 降压模块 IN+
        │
        └───────────────── 车身金属螺丝 ── GND
                              │
   降压模块 OUT+ (3.9V) ───────┼──► 手机 4P 接口的 1 脚
   降压模块 OUT− ──────────────┼──► 手机 4P 接口的 2 脚
   MCU PB3 → 光耦 → ───────────┼──► 手机 4P 接口的 3、4 脚
安装注意
• ACC 取电：钥匙拧到 ACC/ON 才有电，熄火断电，避免亏电。用保险取电器，不要直接破线。
• 降压模块放在通风处，别塞在密封空间。
• 手机固定：用出风口/中控台支架，不要挡住安全气囊和视线。
• 散热：一加 7 Pro 的 90Hz 屏 + 855 发热大，夏天车内暴晒极易过热降频。建议拆掉原后盖，加铝制背夹散热片，最好再加 40mm USB 风扇对着主板吹。
• 音频：一加 7 Pro 没有 3.5mm 耳机孔，需要 USB-C 音频转换器或蓝牙连车机。

九、手机端软件设置（开机后直接进 HiCar）

  1. 设为默认桌面：设置 → 应用 → 默认应用 → 主屏幕应用选 HiCar receiver。或 ADB：
    adb shell cmd package set-home-activity 你的包名/你的Activity
  2. 关掉锁屏：设置 → 安全与锁屏 → 屏幕锁定 → 无。
  3. 保持常亮：我们是 VBAT 供电，系统不认为是"充电"，开发者选项的"充电时屏幕常亮"可能无效。用 ADB：
    adb shell settings put system screen_off_timeout 2147483647
  4. 电池优化白名单：adb shell dumpsys deviceidle whitelist +你的包名
  5. 关闭系统自动更新、禁用不必要的应用通知，减少后台干扰。
  6. 若需要 root 后用 Magisk 模块强制自启 HiCar 也可以，但不是必须。

十、关机处理（如实说明）

熄火后 ACC 断电，降压模块停止输出，手机 VBAT 消失 → 硬关机。这是绝大多数手机改车机的通用做法，ext4/f2fs 文件系统有日志，通常不会损坏数据。

如果你一定要"软关机"：需要让 MCU 在 ACC 断开后还能活 10 秒。做法是从常电（电瓶直通）单独取一路给 MCU 供电，MCU 检测到 ACC 变低后，拉低 PWRKEY 保持 8~10 秒触发关机，再关掉降压模块的 EN 脚。代价是 MCU 常驻耗电约 10~20mA，长期停放会缓慢亏电，建议加电压检测，低于 12.2V 就彻底断电。

十一、风险与排错清单

现象排查
上电无任何反应查保险丝、降压模块输出是否 3.9V；查电池排线是否插紧
亮充电图标但不开机延长 MCU 上电延时到 12~16s；确认 NTC 为 10kΩ
开机后反复重启降压模块电流不足或纹波太大 → 换 XL4015，输出电容加大到 2200µF
随机不开机PWRKEY 飞线虚焊 → 重新焊并点热熔胶固定
机身发烫加强散热，降低屏幕亮度，关闭 90Hz
熄火后几天电瓶亏电检查 ACC 取电是否接错成常电
最后提醒：第一步一定是在台架上用可调电源完整跑通"断电 → 上电 → 自动开机 → 进 HiCar"至少 10 次，确认稳定后再装车。焊接电源键飞线时用放大镜和尖头烙铁，动作要轻，主板焊盘很脆弱。如果你把拍下来的主板照片和电池排线照片发给我，我可以帮你具体标出该焊哪几个点。
